## 3. 주행에서 할 것 **[사람 + 나]**

직선 몇 미터가 필요하다. 2장이 끝난 뒤에 한다.

- [ ] **PID 게인 튜닝** — 전부 런타임 파라미터라 재빌드 없이 물가에서 바로 돈다.
      진입 전 확인 2건: 실부하에서 `ros2 topic hz /filtered/attitude` ≈ 100 Hz,
      발행자 1개. **튜닝 중 btn2 길게(지자기 보정) 금지** — CPU 를 잡아먹어 100 Hz 를 흔든다.
      축별로 (pitch → roll → yaw):
      1. **kp: 소진폭 스텝 응답으로** — 목표 ±3~5° 스텝, 오버슈트 <20 % 까지 올린다.
         ※ 임계진동(ku) 탐색은 부적합 — kp 8.75가 이미 오차 20°에서 창 포화라, 발진 전에
         포화가 먼저 걸려 릴레이형 리밋사이클을 ku 로 오측한다
      2. **ki: 정상상태 오프셋이 남을 때** 0.01부터. **함정: 최대 I 기여 = i_limit × ki**
         (기본 300 × 0.01 = 3 µs 뿐). 목표 오프셋보다 작으면 i_limit 도 같이 키울 것
      3. **kd: 오버슈트가 남을 때만.** 현재 D 는 원시 차분이라 잡음 증폭 + 목표 스텝 킥.
         실제로 켜게 되면 그때 → **[나]** 측정값 미분 + 1차 필터로 변경
      4. AUTO↔MANUAL 전환은 적분을 리셋하지 않는다 — 전환 직후 ki 를 같은 값으로
         `param set` 하면 리셋된다(부수효과 활용). 근본 수정은 5장
      ※ `ki`/`kd`는 dt 흡수형이라 **100 Hz 기준값**이다

- [ ] **PID 게인 영속화** — **[나]** 튜닝 종료 후.
      `ros2 param set`은 재시작하면 사라진다. 저널에서 최종값 회수
      (`journalctl -u fish-robot | grep "게인 변경" | tail`) → 소스 초기화 목록 기본값에
      반영(진실원 한 곳) → 빌드 → 재시작 → 커밋

- [ ] **`speed_k` 확정** ← **속도 쪽에 남은 유일한 일.** 지금 1.0 이라 `Speed_wz` 는
      상대 비교만 된다(노드가 기동마다 경고를 찍는다). 영점·편향은 대기창 영점으로 해결됐으니
      남은 건 배율 하나다.
      표시한 거리(예: 5 m)를 **자력 주행**하며 스톱워치.
      **예인으로 하면 안 된다.** 끌 때는 몸이 안 흔들려 정체압이 온전한데, 실제 유영은
      좌우로 흔들려 정체압이 `cos²β`만큼 깎인다. 예인 배율은 속도를 1~3 % 낮게 만든다.
      ※ 예인 장비를 쓸 때는 CSV 의 `Epoch(s)` 열로 예인 로그와 시간선을 맞출 수 있다
      (10-07 추가. `Time(s)` 는 로거 기동 기준 단조 시계이고, 모든 구간·주기 계산은 그쪽을 쓴다)

- [ ] **꼬리치기 피치 진폭 측정** ← `pressure_lag_ms` 작업의 선결 조건.
      지연 오차는 주기 운동에서 평균이 0이고 τ=1s 필터가 2 Hz를 12.6배 감쇠시키므로
      **정상 순항에서는 거의 문제가 안 된다** (진폭 3°: +0.6 %, 10°: +2.1 %).
      진폭을 재기 전에는 지연을 정밀하게 맞출 이유가 없다. CSV 의 `Hydro_Pitch`로 뽑는다

- [ ] **`pressure_lag_ms` 확정** — 위 진폭이 크게 나왔을 때만.
      제자리 꼬리치기 기록 → 오프라인에서 지연을 훑어 `corr(Q_dyn, sin θ)` 최소화.
      **현재 설정 72 ms 는 11 Hz 시절 값이라 낡았다** — 19.3 Hz 상태머신에서는 대부분의
      샘플이 약 32 ms(온도 사이클만 약 52 ms)다. 출발점은 72 가 아니라 32 로 잡을 것.
      정지 로그로는 검증 불가(ω ≳ 20 °/s 필요).
      ※ 기동 중(비주기)에는 평균이 0이 아니다 — 피치 20 °/s 지속 회전이면 v=0.6에서 +11.4 %

- [ ] **`roll`/`pitch` 오프셋 결정** — roll 은 3.87일 실측 +6.4°로 안정(장착 오프셋으로
      보임), pitch 는 놓는 방식에 좌우되어 상수가 없다. 중성부력 자세와 얽혀 있어
      물에 띄워봐야 정해진다. 정해지면 → **[나]** 목표 오프셋 파라미터

- [ ] **꼬리치기 pitch 편향 측정** — 주행 CSV 에서

## 다 끝나지 않는 것

- **지자기 보정은 조립이 바뀔 때마다 무효**다. 하우징을 닫으면 하드아이언이 통째로 바뀐다
  (실측: 조립 변경마다 지배 축이 옮겨 다녔다 — 최근 3회: Z → Y → Z)
- **로그 총량은 사람이 관리**한다. 73열이 된 뒤 **시간당 약 110 MB**. 안 쓸 때
  `sudo systemctl stop fish-robot`. (2026-10 에 빈 CSV 73개로 15.2 GB 가 샌 전력 — 노드가
  살아 있으면 입력 없이도 100 Hz 로 계속 쓴다. `ps -C data_logger_node` 로 확인할 것)
  정리 시 `config/`는 절대 건드리지 말 것 (`git checkout -- config/`로 복구 가능)
- **서보 PWM 창(1325/1675)은 nRF 펌웨어 창(1250/1750) 안에 있어야** 한다 — 여기가 더
  좁은 건 안전, 넓히는 것만 nRF 와 함께. 이 저장소가 강제할 수 없다
- **조립·거치를 바꾸면 btn1 3초** — 압력 센서 오프셋이 응력으로 뛸 수 있다 (ch2 전력)
